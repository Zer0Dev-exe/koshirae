# Código de Conducta

## Nuestro compromiso

Queremos que participar en este proyecto sea una experiencia libre de acoso para todas las personas, sin importar edad, discapacidad, etnia, identidad o expresión de género, nivel de experiencia, nacionalidad, apariencia, religión u orientación sexual.

## Comportamiento esperado

- Ser respetuoso y constructivo.
- Aceptar críticas técnicas con buena disposición.
- Centrarse en lo que es mejor para el proyecto.

## Comportamiento inaceptable

- Insultos, comentarios despectivos o ataques personales.
- Acoso público o privado.
- Publicar información privada de otras personas sin permiso.

## Aplicación

Quien mantiene el proyecto puede editar o eliminar comentarios, issues y contribuciones que incumplan este código, y vetar temporal o permanentemente a quien lo infrinja. Para reportar conductas, escribe por privado a quien mantiene el proyecto a través de su perfil de GitHub (https://github.com/Zer0Dev-exe).
